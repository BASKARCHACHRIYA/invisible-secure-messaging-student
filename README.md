# invisible-secure-messaging-student
A student project for Shipaton 2026: Next Gen Award. A presence-based secure messaging app featuring Face-Detect Second Lock, Chat Unexist for unknown faces, and 10s photo alerts. Banned screenshots &amp; screen recording. Saves data on Blockchain. Integrated with RevenueCat SDK for secure verification and premium features.
## System Design Flow:
1. Face Detection Second Lock checks for authorized user presence.
2. Unknown Face / Multi-Face detection automatically triggers "Chat Unexist".
3. Private Photos shared create a 10-second viewing alert before auto-deletion.
4. Anti-Leak system blocks screenshots, screen recordings, and external saves.
5. Verification metadata and private photos are securely saved on the Blockchain.
